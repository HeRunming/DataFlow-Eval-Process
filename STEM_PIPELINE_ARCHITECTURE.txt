PIPELINE DATA FLOW (6 Steps)
═══════════════════════════════════════════════════════════════════════════════

Step 0: PREPROCESSING (Rule-based)
┌─────────────────────────────────────────────────────────────────────────────┐
│ StemMCPreprocessorFilter (filter/stem_mc_preprocessor_filter.py)            │
│                                                                             │
│ INPUT: question, text                                                       │
│   question: "题目：{关于DNA... A. ... B. ... C. ... D. ...}"                 │
│   text: "ABCD" (or "A,B,D" or various formats)                              │
│                                                                             │
│ OPERATIONS:                                                                 │
│   1. Extract core proposition (remove wrapper: "题目：{...}")               │
│   2. Normalize answer labels → "A,B,D" format                               │
│   3. Fix M1 format (inline options → add line breaks)                       │
│   4. Parse options → option_a, option_b, option_c, option_d                │
│   5. Filter invalid records (empty question, empty answer, insufficient options)
│                                                                             │
│ OUTPUT: question_clean, answer_label, options_text, option_a/b/c/d,        │
│         num_options                                                         │
│ KEEP RATE: ~98%                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓

Step 1: REWRITING (LLM-based)
┌─────────────────────────────────────────────────────────────────────────────┐
│ StemMCToOpenEndedRewriterGenerator (generate/stem_mc_to_openended_rewriter_generator.py)
│                                                                             │
│ PROMPT: StemMCRewritePrompt (prompts/reasoning/stem.py)                     │
│   - Auto-detects Chinese/English                                           │
│   - Few-shot examples included                                             │
│   - Emphasizes neutrality & no answer leakage                              │
│                                                                             │
│ INPUT:                                                                      │
│   question_clean: "关于DNA复制，下列说法正确的是..."                         │
│   options_text: "A. DNA复制是半保留复制\n B. 复制过程需要解旋酶..."          │
│                                                                             │
│ LLM PROCESSING:                                                             │
│   - Pass question + options to LLM with bilingual Few-Shot                  │
│   - LLM generates neutral rewrite                                           │
│   - Post-process output:                                                    │
│     * Remove prefixes ("改写后:", "Rewritten:")                             │
│     * Remove think tags (<think>...</think>)                                │
│     * Remove markdown headers                                               │
│                                                                             │
│ OUTPUT: question_rewritten                                                  │
│   "请说明DNA复制的机制和过程，包括：(1) 复制方式的特点；(2) 所需酶的作用...│
│                                                                             │
│ KEEP RATE: 100% (with empty filtering)                                      │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓

Step 2: ANSWER LEAK DETECTION (LLM Judge)
┌─────────────────────────────────────────────────────────────────────────────┐
│ StemMCAnswerLeakFilter (filter/stem_mc_answer_leak_filter.py)              │
│                                                                             │
│ PROMPT: StemMCAnswerLeakDetectionPrompt (prompts/reasoning/stem.py)        │
│   - Evaluates if rewritten question reveals correct answers                │
│   - Identifies 5 leak types:                                               │
│     1. direct_indication (states correct options directly)                 │
│     2. implicit_selection (structure implies some options matter more)     │
│     3. answer_mirroring (logic mirrors correct answer pattern)             │
│     4. forced_analysis (only feasible path leads to correct answers)       │
│     5. terminology_bias (word choice suggests certain answers)             │
│                                                                             │
│ INPUT:                                                                      │
│   question_rewritten: "请说明DNA复制的机制..."                              │
│   answer_label: "A,B,C,D"                                                   │
│   options_text: (original options)                                          │
│                                                                             │
│ LLM JUDGE OUTPUT:                                                           │
│   {                                                                         │
│     "has_leak": false/true,                                                │
│     "leak_type": "<type>" or null,                                         │
│     "confidence": "high|medium|low"                                        │
│   }                                                                         │
│                                                                             │
│ FILTERING:                                                                  │
│   - Keep: has_leak = false ✓                                                │
│   - Filter: has_leak = true ✗                                               │
│                                                                             │
│ KEEP RATE: ~85-90% (some questions have subtle answer leakage)             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓

Step 3: N-GRAM DEDUPLICATION (Rule-based)
┌─────────────────────────────────────────────────────────────────────────────┐
│ ReasoningAnswerNgramFilter (filter/reasoning_answer_ngram_filter.py)      │
│                                                                             │
│ OPERATION:                                                                  │
│   - Compare question_clean (reference) vs question_rewritten (rewrite)     │
│   - Calculate n-gram similarity (5-gram)                                    │
│   - Keep only if ≥30% new n-grams (min_score=0.3)                         │
│   - Filter samples where rewrite too similar to original                    │
│                                                                             │
│ PURPOSE: Ensure substantial rewriting, not just minor rewording            │
│                                                                             │
│ KEEP RATE: ~95% (minor n-gram dedup filtering)                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓

Step 4: COLUMN ALIGNMENT (Rule-based)
┌─────────────────────────────────────────────────────────────────────────────┐
│ StemColumnAlignGenerator (generate/stem_column_align_generator.py)         │
│                                                                             │
│ OPERATION:                                                                  │
│   - Rename field: question_rewritten → question                            │
│   - Keep only open_ended format columns:                                    │
│     * answer_model, dataset_name, id, not_zh, ori, std_answer_model,      │
│     * text, title, question                                                │
│   - Drop intermediate processing columns                                    │
│                                                                             │
│ OUTPUT: DataFrame aligned to open_ended dataset schema                     │
│                                                                             │
│ KEEP RATE: 100% (pure column transformation)                               │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓

Step 5: SUBJECT TAGGING (LLM-based)
┌─────────────────────────────────────────────────────────────────────────────┐
│ StemSubjectTaggerSampleEvaluator (eval/stem_subject_tagger_sample_evaluator.py)
│                                                                             │
│ PROMPT: StemSubjectTaggingPrompt (prompts/reasoning/stem.py)               │
│   - 6 subject categories: Math, Physics, Chemistry, Biology, CS, Other    │
│   - Outputs confidence level: high/medium/low                              │
│                                                                             │
│ INPUT: question                                                             │
│                                                                             │
│ LLM OUTPUT:                                                                 │
│   {                                                                         │
│     "subject": "数学" | "物理" | "化学" | "生物" | "计算机科学" | "其他",    │
│     "confidence": "high" | "medium" | "low"                               │
│   }                                                                         │
│                                                                             │
│ OUTPUT FIELDS: subject_tag, subject_conf                                   │
│                                                                             │
│ KEEP RATE: 100% (classification always succeeds)                           │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓

FINAL OUTPUT
┌─────────────────────────────────────────────────────────────────────────────┐
│ Open-Ended STEM Questions (open_ended dataset format)                      │
│                                                                             │
│ Fields: question, subject_tag, subject_conf, + other open_ended fields     │
│ Format: JSONL                                                               │
│ Example: {                                                                  │
│   "question": "请说明DNA复制的机制和过程...",                               │
│   "subject_tag": "生物",                                                    │
│   "subject_conf": "high",                                                   │
│   "text": "<answer text>",                                                  │
│   "title": "<question title>"                                              │
│ }                                                                           │
└─────────────────────────────────────────────────────────────────────────────┘

CUMULATIVE RETENTION
═══════════════════════════════════════════════════════════════════════════════

Input: 20,000 samples
  ↓ Step 0 (Preprocessing): 20,000 × 0.98 = 19,600
  ↓ Step 1 (LLM Rewrite): 19,600 × 1.00 = 19,600
  ↓ Step 2 (Answer Leak Filter): 19,600 × 0.87 = 17,052 ★ (PRIMARY FILTER)
  ↓ Step 3 (N-gram Filter): 17,052 × 0.95 = 16,199
  ↓ Step 4 (Column Align): 16,199 × 1.00 = 16,199
  ↓ Step 5 (Subject Tag): 16,199 × 1.00 = 16,199

Final Output: ~16,000 samples (80% retention from input)

KEY RETENTION FACTORS:
- Step 0: Data quality issues (~2% loss)
- Step 2: Answer leakage detection (~13% loss) ★ PRIMARY BOTTLENECK
- Step 3: Over-rewriting (too much change) (~5% loss)

  - DF_API_KEY: API authentication key
  - DF_MODEL_NAME: Model name (default: gpt-4o)

USAGE
═══════════════════════════════════════════════════════════════════════════════

1. Set environment variables:
   export DF_API_URL="https://your-api/v1/chat/completions"
   export DF_API_KEY="your-key"
   export DF_MODEL_NAME="your-model"

2. Prepare input JSONL:
   {"question": "题目：{...}", "text": "ABCD"}
   {"question": "题目：{...}", "text": "A,B"}
   ...

3. Run pipeline:
   cd /data/workspace/DataFlow
   python -m dataflow.statics.pipelines.api_pipelines.stem_mc_to_openended_pipeline

4. Check output:
   ls -lah ./cache_stem_mc_rewrite/
   - mc_rewrite_step0.jsonl (after preprocessing)
   - mc_rewrite_step1.jsonl (after rewriting)
   - mc_rewrite_step2.jsonl (after leak filter)
   - mc_rewrite_step3.jsonl (after n-gram filter)
   - mc_rewrite_step4.jsonl (after column align)
   - mc_rewrite_step5.jsonl (after subject tagging)
